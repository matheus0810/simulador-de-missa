# Simulador de Missa

Joguinho 2D em estilo 8 bits em que você é o padre e celebra a Missa do começo ao fim: sacristia, procissão de entrada, Liturgia da Palavra, Oração Eucarística, comunhão e ritos finais.

## Como jogar

Abra `index.html` no navegador, ou acesse a versão publicada na Vercel.

- Escolha a Oração Eucarística (I a IV), o idioma (latim ou português), a orientação (ad orientem ou versus populum), a casula (gótica ou romana) e se haverá incenso.
- O dia litúrgico é sorteado a cada Missa e define a cor das vestes, o Glória e o prefácio.
- Escolha as fórmulas e gestos certos com o mouse ou as teclas 1–5. Use V para virar-se (ad orientem), M para a música e F para tela cheia.

## Observações

Os textos litúrgicos aparecem resumidos para o jogo; alguns trechos em português são adaptações. Para celebrar de verdade, use o Missal Romano.

A música de fundo, que toca a Missa toda, é uma versão 8 bits do Prelúdio em Dó (BWV 846) de J. S. Bach, em domínio público.

## Publicação

É um site estático de um arquivo só, sem etapa de build. Na Vercel, importe o repositório com o Framework Preset "Other".
